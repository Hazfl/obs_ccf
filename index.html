OBS 적용 방법

      
    
        
  1. OBS에서 소스 추가 → 브라우저를 선택합니다.
    2. 
        
  2. URL에 코코포리아 룸 주소(스탯카드는 /characters/ID 포함)를 입력합니다.
    3. 
        
  3. 커스텀 CSS 칸에 위에서 생성된 코드를 그대로 붙여넣습니다.
    4. 
        
  4. 소스를 우클릭 → 속성에서 크기를 맞추고, Alt + 드래그로 필요한 부분만 잘라냅니다.
    5. 
        
  5. 여러 요소(보드/말풍선/채팅/스탯카드)를 같이 쓰려면 소스를 각각 따로 추가하세요.
    6.
